# FTNN-Ps 迁移学习建立飞机单位重量剩余功率模型方法

[中文](#中文) | [English](#english)

## 中文

FTNN-Ps是一个利用稀疏飞行数据来辨识飞机单位重量剩余功率（Ps）曲面模型的方法。 其能够建立高维复杂工况下的 Ps 连续模型。该方法分为两个步骤：1.基于CFD数据建立预训练模型；2.基于稀疏飞行数据修正预训练模型得到 Ps 微调模型。

本仓库提供的论文实例采用 MSFS2020 生成的源域数据和 基于NASA CR1765 报告生成的目标域飞行仿真轨迹数据。

本仓库中我们开源了该方法的核心代码部分与测试数据。

### 1. 目录内容

```text
FTNN-review/
├── Pretrain-MODEL/     # 基于 CFD 数据的源域预训练模型建立代码
├── FTNN-model/         # 基于飞行数据的 FTNN-Ps 微调与模型验证代码
├── inputdata/          # 所有输入数据文件
├── appendix/           # 其他对比方法代码，用于检验FTNN-Ps方法的优越性
├── requirements-reproduction.txt # 编译环境配置
└── README.md
```

### 2. 如何运行预训练模型建立任务

```powershell
python train_pcnn_5D.py
```

### 3. 如何运行 FTNN-Ps 模型建立任务

```powershell
python run_ftnn_50.py
```

### 4. 简单的测试 FTNN-Ps 训练结果

先完成第 3 步的训练（生成 `results_10sources_5lr`）

```powershell
python evaluate_tracks_4_15.py
```

## English

FTNN-Ps is a method that identifies an aircraft specific excess power (Ps) surface model from sparse flight data. It can build a continuous Ps model under high-dimensional and complex operating conditions. The method consists of two steps: (1) build a pretrained model from CFD data; (2) refine the pretrained model with sparse flight data to obtain the Ps fine-tuned model.

The paper example provided in this repository uses source-domain data generated by MSFS2020 and target-domain flight-simulation trajectory data generated from the NASA CR1765 report.

This repository open-sources the core code and test data of the method.

### 1. Contents

```text
FTNN-review/
├── Pretrain-MODEL/     # Source-domain pretrained-model code based on CFD data
├── FTNN-model/         # FTNN-Ps fine-tuning and model-validation code based on flight data
├── inputdata/          # All input data files
├── appendix/           # Code for other comparison methods, used to verify the advantage of FTNN-Ps
├── requirements-reproduction.txt # Environment configuration
└── README.md
```

### 2. How to run the pretrained-model task

```powershell
python train_pcnn_5D.py
```

### 3. How to run the FTNN-Ps model task

```powershell
python run_ftnn_50.py
```

### 4. A simple test of the FTNN-Ps training results

First complete Step 3 (generating `results_10sources_5lr`).

```powershell
python evaluate_tracks_4_15.py
```
